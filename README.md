# hiccai-creative — 创意与商业内容操盘手

输入品牌、产品或服务，输出贴近受众需要的营销成品：让内容被看见，让利益被归给品牌，让有需求的人走到购买、咨询或预约。

v4.0 保留 72 张创意卡和四套方法资产，新增销售与线索模式；“爆款”作为需要真实数据验证的目标，不承诺必爆或保销量。

## 使用

克隆到所用 runtime 的 skills 目录，例如：

```bash
git clone https://github.com/laixi969-coder/hiccai-creative.git \
  ~/.claude/skills/hiccai-creative
```

其他 runtime 使用各自的 skills 路径。已安装用户在对应克隆目录执行 `git pull --ff-only`。本仓库自包含，无需额外安装相关 skill。

直接说明需要的成品、受众与业务目标：

- “给宠物友好咖啡馆写 30 条小红书标题，要让附近养狗的人找到我们。”
- “为通勤杯写一篇完整带货笔记，用品牌账号口吻，有活人感，不要假装买家亲测。”
- “我们做企业培训，给一条 30 秒获客视频和预约后的欢迎回复，筛选有明确需求的企业。”
- “为矿泉水品牌出三个创意方向，让人记住午餐搭配场景，先不推购买。”
- “输出完整营销全案，兼顾品牌曝光与销售，直接完成，不用逐步确认。”

提供已有产品资料、用户反馈、品牌资产、价格条件和渠道入口，能让证据与行动路径更具体。资料不足会标明创作假设，不能编造效果、案例或优惠。

## 八种交付模式

| 模式 | 交付 |
|---|---|
| [一 提案](modes/01-proposal.md) | 按需求页数输出 PPT 文案，不强凑50页 |
| [二 小红书全案](modes/02-xhs-fullplan.md) | 需求、内容分工、节奏、完整笔记 Demo、承接与验证 |
| [三 标题与内容](modes/03-title-factory.md) | 标题、广告语或完整笔记，按请求数量与形式交付 |
| [四 创意故事](modes/04-creative-story.md) | 可比较方向或完整故事/脚本，尊重指定载体 |
| [五 洞察转创意](modes/05-insight-to-idea.md) | 创意、画面、标题、脚本、品牌落点与传播钩子 |
| [六 广告全案](modes/06-full-campaign.md) | 策略、方向、文案、视觉 Prompt 与商业落地 |
| [七 方案](modes/07-full-plan.md) | 带来源、假设与取舍的诊断、市场、人群、策略和执行方案 |
| [八 销售与线索](modes/08-conversion.md) | 产品带货、销售页、服务预约、B2B获客与销售回复 |

先识别交付物，再叠加商业目标。“10条带货标题”只交标题；“小红书留资全案”整合增长与线索承接；只给品牌名时先给三个创意雏形，供选择。

用户只要方向才停在方向层；要求完整成品、直接写或“你定”就完成授权范围。输出内容不会自动发布、投放或发送。

## 输出如何兼顾传播与商业

1. **受众需求**：触发场景、想完成的事、已有替代、选择阻力；不只写年龄和抽象情绪。
2. **传播吸引力**：标题与开场提供值得关注的承诺，正文兑现；有合理分享动机才设计传播，不强逼每篇互动。
3. **品牌记忆**：需求场景与品牌利益形成关联，真实特点参与关键画面或判断，不只末尾贴 logo。
4. **商业承接**：收益、证据、异议、条件与主要 CTA 对齐；服务说明交付边界，线索定义合格标准。
5. **效果验证**：曝光、品牌关联、净成交、合格线索、有效预约分别衡量；单变量试验，不把点赞或编辑自评分当销量预测。

保留**活人感**：具体身份、自然语气、可感知场景与真实取舍。移除“每篇强制一个数字、一段不顺”的要求，避免虚构亲测、口碑和聊天记录。真实体验可直接用，情景演绎需说明性质。

## 结构与方法资产

[SKILL.md](SKILL.md) 包含路由、业务目标和全局质量要求；`modes/` 按需加载；[效果验证](references/performance-validation.md) 仅用于完整方案与复盘。

原有创意资产保留：

- [72变创意卡牌](references/creative-72-transformations/SKILL.md)：八族创意机制，用于方向差异。
- [创意生成五步法](references/creative-methods/five-step-ideation/SKILL.md)：从材料组合 Big Idea。
- [传播三法则](references/creative-methods/tipping-three-laws/SKILL.md)：谁传、传什么、在哪里传。
- [SUCCESs](references/creative-methods/stickiness-succes/SKILL.md)：信息理解与记忆。

子资产的数量、载体与格式不覆盖用户 brief；选择过程和内部质检不进入文案成品。

## 验证与维护

[test-prompts.json](test-prompts.json) 覆盖八模式、混合路由、品牌归属、标题兑现、活人感、事实边界、带货、服务、线索与实验设计。每例给出请求和可观察的通过/失败条件，可交给支持技能的模型执行并人工评审。

结构校验与人工情境走查不能证明实际传播或销售提升；上线后仍应按真实基线、归因口径和业务结果迭代。
