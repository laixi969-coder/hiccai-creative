# 模式一：提案模式

遵循主 SKILL.md。交付可直接用于 PPT 的分页文案，按用户指定页数、受众和深度组织；未给页数时按议题充分性安排，不为凑 50 页灌水。

## 内容组织

先内部确定业务目标、受众需求、品牌证据、主张与行动路径。页面叙事可按：业务问题 → 需求场景 → 品牌选择理由 → 核心创意 → 内容/触点分工 → 落地与衡量。不要只有品牌宣言，没有消费者利益和执行落点。

每页 `P[页码]：[核心观点] / [支撑文案]`，一页一个意思；主文案尽量≤50字，必要的数据、来源和条款可放附注，不因字数限制删除依据。用户要求设计说明时再补视觉建议。

用户只要骨架时交骨架；要求完整提案时直接完成。用户明确要共同定框架才先确认，不额外设置固定审批。

复杂定位可读 `references/creative-methods/five-step-ideation/SKILL.md`；需要创意突破读 `references/creative-72-transformations/SKILL.md`；精炼核心页可读 `references/creative-methods/stickiness-succes/SKILL.md`。不展示内部选卡和打分。

## 商业闭环

曝光提案明确需求场景、品牌记忆资产与传播理由；销售/线索提案另读 `modes/08-conversion.md`，包含证据、异议、承接和指标。完整营销提案读 `references/performance-validation.md`，把测量安排落实到对应页面。来源和创作假设可以列附注，不能包装成确定市场结论。
