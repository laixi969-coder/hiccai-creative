# 模式四：创意故事模式

> 归属：`hiccai-creative` · 由主 SKILL.md 路由进入。
> **进入本文件前，主 SKILL.md 的「交付总纲」「三条硬门槛」「底层武器库」已生效，本文件只补本模式细则。**

## 适用场景
需要有裂变基因的品牌故事方向 / 传播创意 / 广告脚本种子

## 方法资产
- **72变**（`references/creative-72-transformations/`）：方向生产器，**强制**——第一步必须先加载，按 brief 选 3 个不同族
- **组合机**（`references/creative-methods/five-step-ideation/`）：每个方向的「故事感表达」用「旧元素新组合」焊接（拆元素库→跨域焊接→3 问检验）
- **附着力法则**（`references/creative-methods/tipping-three-laws/`）：每个方向的裂变钩子过「附着力 5 问」

## Big Idea 评估标准（来自创意总监视角）

每个创意方向在输出前，内部用五维判断，挑出最有资格成为 Big Idea 的：

| 维度 | 问题 |
|---|---|
| 策略承载力 | 它能不能承载品牌定位，而不只是一支好看的片子？ |
| 品牌资产价值 | 它会不会沉淀成可长期使用的品牌符号？ |
| 商业爆发力 | 它能不能降低消费者认知摩擦，直接推动行动？ |
| 媒介延展性 | 它能不能从一个核心创意延展到多个触点？ |
| 执行可行性 | 它在资源限制内能不能真正拍出来？ |

## 第一步：先用「创意72变」选方向，再直接输出3个创意故事方向

> **铁律：这一步只交付「3 个创意方向」，不交付脚本、不交付标题、不交付文案。** 脚本/标题是第二步以后的事。

**0️⃣ 前置：调用创意72变**（本模式的方向生产器，强制，不可跳过）：
- 加载 `references/creative-72-transformations/SKILL.md` 母索引，按 brief 走「选族 → 选卡」逻辑
- 用「多样性强制检查」挑出 **3 个不同族**的卡组合（如 A 形性 + G 叙事 + C 视角，禁同族换皮）
- 每个方向标注：**用了哪张卡 + 为什么这张卡**（保证方向差异是「族」级的，不是换个说法）
- **注意**：72变 SKILL.md 里的「四段输出格式（选族/选卡/执行思路/质检）」在本 skill 内只作内部草稿，选族理由与质检结果不进交付正文——交付正文只出现下方「1️⃣」定义的 3 个方向

**1️⃣ 输出 3 个创意故事方向**（收到品牌信息后，不分析不解释，直接输出。格式）：

> 关键：3 个方向**每个都要展开到「能想象成品长什么样」的完整雏形**，让用户看得懂、比得了、选得下。禁止只给一两句骨架。

**创意故事[N]**（卡：X族 · 编号 · 载体：Y）

【标题】一句话，抓眼球
【一句话主题】这个创意在说什么（≤20字）
【载体形式】必填（视频/TVC、装置/快闪、互动H5、联名/IP、事件/节日、海报/长图、音乐、UGC挑战、产品/包装、游戏化）
【完整雏形】像成品一样描述——长什么样 / 用户会经历什么 / 品牌怎么出现（具体到可想象，不是一两句骨架）
【裂变钩子】一句话，短、狠、易转发
【为什么成立】1-2 句：凭什么打动目标人群

**载体多样性铁律**：
- 3 个方向的载体必须互不相同，且 **至少 2 个不是视频**（如 视频 + 装置 + 联名，或 海报 + 事件 + 音乐）
- 若 3 个方向都是视频/都是同一载体 → 判为**载体路径依赖**，必须换卡重出
- 族不同 + 载体不同 = 真正的多样性（双重校验）

**🔴 用户选择检查点（强制，禁止自己选）**：
- 3 个完整雏形输出后**必须停下**，附一张方向对比表帮用户决策：

| 方向 | 载体 | 成本量级 | 传播力 | 适合谁 |
|---|---|---|---|---|
| 方向1 | 装置/快闪 | 中高 | 现场强、口碑型 | 线下体验型品牌 |
| 方向2 | 长图文/海报 | 低 | 收藏型、长效 | 预算少、要记忆点 |
| 方向3 | 事件/节日 | 中 | 话题型、易出圈 | 想造势、要话题 |

- 问用户：「选哪个方向展开？（回复 1/2/3）」
- **禁止自己默认选一个往下走**——用户不选就等；用户说「你定」才能选一个并说明理由
- **未获用户选择前，不得进入第二步**

## 第二步：用户回复"1"/"2"/"3"后，按该方向的载体形式展开

**按载体分派（不是一律写剧本）**：

| 载体形式 | 第二步展开内容 |
|---|---|
| 视频 / TVC | 完整故事脚本（片名/一句话主题/梗概/完整脚本/AI提炼/AI生图Prompt） |
| 线下装置 / 快闪 | 装置方案（概念/空间设计/动线/交互点/传播设计/物料清单/AI生图Prompt） |
| 互动 H5 / 小程序 | 交互设计（核心机制/用户路径/玩点/分享钩子/技术栈建议） |
| 联名 / IP周边 | 联名企划（对象选择/共创点/产品形态/发售节奏/传播设计） |
| 事件营销 / 节日 | 事件方案（事件创意/现场流程/参与者机制/二传设计/风险预案） |
| 长图文 / 海报 | 视觉文案（主视觉创意/文案成稿/版式结构/AI生图Prompt） |
| 产品设计 / 包装 | 产品创意（设计概念/功能点/场景/命名/传播点） |
| 音乐 / 歌曲 | 音乐企划（歌词/旋律方向/传播点/翻唱空间） |
| UGC 挑战 / 实验 | 参与机制（玩法规则/激励/拍摄脚本/数据验证点） |
| 游戏化体验 | 游戏设计（核心玩法/关卡/奖励/传播设计） |

视频展开仍用固定格式：
一、片名
二、一句话主题
三、故事梗概
四、完整故事脚本（有开场、推进、情绪变化、记忆点、收束）
五、可直接交给AI的提炼内容：
- 主题句 / 情绪关键词 / 视觉关键词
- 关键场景 / 关键动作 / 关键对白旁白
- 品牌出现方式 / 裂变钩子
- 可供二创的核心情境 / 可供二创的核心句式
六、AI生图Prompt套组（读 `modes/ai-image-prompt.md`）

## 创意判断优先级
真实洞察 > 情绪共鸣 > 社交裂变潜力 > 二创空间 > 品牌自然贴合 > 画面感 > 新鲜度

## 每个创意必须具备（≥5项）
- 一句话就能说清，并且让人想转发
- 有反直觉点、反差感或新鲜视角
- 有一句容易被引用/截图/传播的话
- 有一个容易被模仿的情境或动作
- 有让网友接一句/站队/玩梗的口子
- 有切片感，单独一幕也能成立
- 有"我也想这么发""我也经历过"的感觉

## 禁止
- 分析创意、解释洞察、解释传播性
- 提案腔、空泛价值观、套路化热血
- 品牌硬植入、话说死（要留接话空间）
- 推平台/媒介/预算/排期
