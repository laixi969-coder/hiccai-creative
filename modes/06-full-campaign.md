# 模式六：广告全案模式

遵循主 SKILL.md。用户要完整全案就一次完成策略、创意、文案与视觉 Prompt；只有明确要求分步共创时逐步确认。

## 1. 策略成品

给简洁且可决策的结论：当前业务问题与依据、核心受众和触发场景、主要阻力、品牌可信优势、一个核心主张、主目标与辅助目标。诊断是假设时注明，不把用户需求默认判成“假需求”。读 `references/creative-methods/five-step-ideation/SKILL.md` 支撑组合。

## 2. 创意方向

读 `references/creative-72-transformations/SKILL.md`，生成默认 3 个不同机制的方向，包含方向名、核心创意、如何展开、品牌在关键情节中的作用、可记忆表达和两个触点实例。用户指定渠道/载体/预算时在限制内差异化。

内部检验策略承载、品牌资产、商业作用、媒介延展与执行可行性；交付推荐方向与简短取舍，不展示自评分。完整全案默认沿推荐方向完成后续，不能停在让用户选择。

传播机制按需读 `references/creative-methods/tipping-three-laws/SKILL.md`，说明谁把什么传给谁、为何传。卖点与传播点必须能回到同一品牌利益。

## 3. 文案成品

沿确认或推荐方向给：Campaign主题、KV主副标题、所需渠道成稿、视频脚本和可持续记忆表达。用户未指定时默认一组KV、一篇适配主渠道的完整社媒文案、15秒与30秒脚本；已有品牌语就复用，不强造新宣言。

按 `references/creative-methods/stickiness-succes/SKILL.md` 内部检查信息与记忆。脚本的画面、口播、字幕与时长可执行；品牌不只在末尾署名。销售/获客全案另读 `modes/08-conversion.md`，提供对应承接成稿，保证广告与落地页/咨询信息一致。

## 4. 视觉与落地

读 `modes/ai-image-prompt.md` 交付 KV 和关键场景 Prompt；图像不得捏造产品能力、证书、客户背书。给触点分工和必要素材清单，现有素材与待制作区分。

读 `references/performance-validation.md`，附简短主指标与实验安排；用户只要创意成品时不扩充媒体采购计划。
