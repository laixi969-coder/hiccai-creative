## 0. 为什么要做这件事

每个创意人、广告人、品牌人都经历过这 3 秒的迷茫：
> "这个 brief 我能往哪里入手？"

《创意72变》这套卡牌的价值，就是给这 3 秒一个回答：**往 72 个方向之一变。**

但 72 张物理卡有 3 个缺点让人没法在实战里持续用：
- **不知道怎么挑**（72 张太多，每次都得洗半天）
- **不知道能不能组合**（卡和卡之间有没有协同？）
- **不知道什么时候不该用**（变了一半发现不匹配）

蒸馏后的 skill 集把这 3 个痛点都解决了：
1. **72 → 8**：按族群聚类，决策树清晰
2. **每族都有"组合拳"**：高频好用组合直接给出
3. **红线和边界**：每族都标明何时不适用

---

## 1. 整套卡的核心命题（3 句话记一辈子）

1. **创意不靠凭空发明，靠"有方向的极端化变形"。**
2. **先选族，再选卡，最后载体。不要反过来。**
3. **不够极端的"变"等于没变。**

> 第 3 点是最容易栽跟头的——80% 的"创意缺力度"问题，都出在"变完看上去跟没变差不多"。

## 4. 5 条核心红线（容易栽的坑）

- ❌ **温和的变**：logo 改小一点、slogan 换说法 = 等于没变
- ❌ **极端但无故事逻辑**：反差大但读者记不住动机
- ❌ **先选载体再凑创意**："我们做个 H5" 开头 = 必败
- ❌ **明星/流量当一切**：明星抢戏产品隐身
- ❌ **执行 = 50 分**：idea 惊艳但拍摄粗糙、文案拉胯

> 最致命的一条（meta 红线）：**面对 72 张卡犹豫不决，开了无数次 brainstorm，最后选了"安全组合"。**
> 这反倒是最常见的失败——把 72 张卡当 KPI 而不是启发工具。**懂得放弃，敢于极端，才是用好这套卡的标志。**

```
   - 有场子 → F19 装置
   - 有数据 → D18 实验

   - 一段剧情 → G

```

## 9. 72 → 8 的归并逻辑（理解本质用）

72 张看似独立，其实本质是 8 大族群（每个"变"的对象）+ 3 种变向（怎么变）：

```
变向 1：极端化 Magnify → 02 03 05 09 51 55 67
变向 2：错位化 Deflect → 04 11 22 25 27 28 33 35
变向 3：合作化 Collaborate → 13-17 36 40 42 44
```

任何"变 X"卡片 = 某个族群 + 某种变向的组合。

> 例：G49"变错为对" = G（叙事语义族）+ 错位化变向 + 反转语义
> 例：H14"变成 IP" = H（杠杆族）+ 合作化变向 + 长期资产语义

理解了这个底层结构，你就不必死记硬背 72 张卡——只要拿到 brief，问"我想让它往哪个方向变？"

## 10. 写在最后

《创意72变》是一台**3 步机器**：

```
已知的 idea
   → 选族（变什么）
      → 选卡（怎么变）
         → 极端化（变多大）
```

卡只是引导，**你的判断力**才是产物。

希望这套 skill 成为你创意工具箱里的常驻工具——不是替你思考，而是帮你**3 秒选对方向**。
