# 创意72变 · README

## 是什么

一套把 72 个「变 X」创意手法蒸馏成的 agent 可调用 skill 集。每个「变 X」曾经是实体卡牌上的一条创意启发术——本 skill 把它数字化、结构化、可路由化。

## 怎么用

### 场景 1：用户给了 brief，要创意方向

加载本 skill 的 `SKILL.md`，按「选族逻辑」选 1–2 个主题，再加载对应 theme 的 SKILL.md，深入到具体卡。**一次至少挑 2–3 张卡组合**——单卡威力有限。

### 场景 2：用户要做脑暴 / 洗牌

直接说「来个随机创意洗牌」，skill 会从 8 大主题随机推荐组合。

### 场景 3：用户在做方案，要选媒介或文案

「选族」部分会推荐移交：
- **文案主笔** → `hiccai-wenan` 或 `hiccai-master-copywriter`
- **KV 封面** → `hiccai-title-pic`
- **短视频脚本** → `hiccai-douyin`
- **小红书内容** → `hiccai-xhs`

## 8 大主题一览

| # | 主题 | 适合谁 |
|---|---|---|
| A | 形性重构 | 视觉奇观/形象记忆 |
| B | 时空错位 | 复古/穿越/低预算 |
| C | 视角重置 | 第一人称/沉浸式 |
| D | 性格置换 | 品牌人格/魔性/温情 |
| E | IP 与关系 | 联名/IP 资产/明星 |
| F | 参与互动 | 事件/H5/装置 |
| G | 叙事语义 | Hero film/long copy/公益 |
| H | 前瞻杠杆 | 借势/social/科技/媒介 |

## 7 条核心使用纪律

1. **先选族，再选卡，再载体** — 不要反过来
2. **必须组合** — 单卡太平庸，2–3 张才有杀伤力
3. **必须极端** — 温和的变等于没变
4. **必须有故事** — 反差里要顺承因果
5. **必须有 case** — 没案例支撑的"变"是空中楼阁
6. **必须极端化执行** — idea 10%，执行 90%
7. **必须质检** — 4 关交叉：极端/故事/可行/品牌一致
