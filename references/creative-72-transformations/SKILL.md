# 创意72变（Creative 72 Transformations · 母索引）

**72 张「变 X」卡 = 72 个创意起步方向，8 大主题归并，3 步选卡法。**

本入口 skill 的三个职责：
1. **路由**：根据 brief 特征，判断该往 8 大主题中哪个走，并加载对应 sub-skill。
2. **选卡**：在主题内挑 1–3 张适配卡（不只一张！），按「极端化」原则组合。
3. **质检**：用统一的「好创意的红线」把关，确保不是温和的"小变"，而是有戏剧性的"大变"。

## 二、选族逻辑（先定主题，再选卡）

### 情形 1：用户说「我想用 72 张卡洗个牌」
- 不需要理由，洗牌即可。直接随机抽 1–3 张作为启发方向。

### 情形 2：用户给了一个 brief —— 按 brief 特征选族

| brief 特征 | 推荐主题 | 第二备选 |
|---|---|---|
| 「产品介绍 / 卖点很硬 / 缺乏戏剧性」 | **A 形性重构** | H 杠杆 |
| 「我们想复古 / 致敬经典 / 跨代沟通」 | **B 时空错位** | G 叙事 |
| 「我们是新品牌 / 需要第一印象冲击」 | **D 性格置换** | E IP |
| 「想请达人/明星合作」 | **E IP 与关系** | F 参与 |
| 「想让用户参与进来」 | **F 参与互动** | H 杠杆 |
| 「想讲一个动人的品牌故事」 | **G 叙事语义** | C 视角 |
| 「预算不多 / 借势 / 蹭话题」 | **H 前瞻杠杆** | F 参与 |
| 「想在社交媒体出圈 / 找 viral idea」 | **D 性格** + **H 杠杆** | — |
| 「想做一支 Hero film / 仪式感大片」 | **G 叙事** + **A 形性** | — |
| 「信息没记忆点 / 想让人记住」 | **H 60 文案主导 / 63 单一要素** | D 性格 |

### 情形 3：用户没 brief —— 按品类 / 场景选族

| 场景 | 推荐主题 |
|---|---|
| 快消/食品/饮料 | D 性格 + H 杠杆（魔性洗脑） |
| 美妆/时尚/奢侈 | D 性格 + E IP + G 叙事（高级感） |
| 科技/SaaS | D 性格 + H 杠杆（科技感） |
| 公益/CSR | G 叙事 + C 视角 + H 杠杆（公益 23） |
| 汽车/工业品 | A 形性 + G 叙事 + H 杠杆（视觉奇观） |
| 金融/B 端 | G 叙事 + H 杠杆（沉稳文案） |
| 文旅/餐饮 | B 时空 + F 参与 + H 杠杆（本地化） |
| 教育/知识付费 | D 性格 + G 叙事（人格化讲师） |

> ⚠️ **此表是「起点推荐」不是「唯一答案」。** 命中同一行后，必须再选一个**不同字母**的反差备选族（如快消选了 D+H，反差备选族选 A 或 F），否则容易陷入路径依赖（见「三、工作流」步骤 5）。

## 三、统一工作流（每次用 72 变都走这 6 步）

> **铁律 1：先选族，再选卡，最后载体。不要反过来。**
> **铁律 2：必须出 ≥2 个不同族的方向再对比，禁止一条线走到黑。**

1. **接到 brief** → 整理出 3 个信息：受众 / 信息 / 预算
2. **走选族逻辑** → 用上面 3 个表，定 1 个主主题 + **至少 1 个「反差备选族」**（与主族不同字母）
3. **加载 sub-skill** → 读 `themes/<主主题>/SKILL.md`，对照卡的具体描述与案例
4. **挑 2–3 张卡做组合** → 1 张定方向 + 1 张定强度 + 1 张定呈现
5. **🔴 多样性强制检查**（新增，防路径依赖）：
   - 用主族产出方向 A → **换到「反差备选族」再产出方向 B**（B 必须与 A 不同族、不同载体、不同卡）
   - 若方向 B 与方向 A 的载体/调性/卡组高度相似（如同一套「方言神曲」换皮）→ 判为**换汤不换药**，必须再换族产出方向 C
   - 交付时列出 A/B/C 三个方向让用户选，**禁止只交付一个方向**
6. **走质检 4 关**（任一不过就回炉）：
   - **极端关**：变之前和之后，反差有 30%+ 吗？没有等于没变。
   - **故事关**：反差里有清晰的因果链吗？没有则变成装怪。
   - **可行关**：选定载体（视频 / 装置 / 文案 / 互动）的成本和效果匹配吗？
   - **品牌一致关**：这个 idea 放在隔壁品牌上也能成立吗？能 = 没差异点。

🔴 **CHECKPOINT · 质检未过必须回炉**：四关任一 ✗ → 回到步骤 4 换卡重选，重试上限 2 次；2 次后仍不过 → 换主题族（回到步骤 2）重来，禁止带着 ✗ 项继续输出。

## 三·五、失败模式与恢复（if → then 三段式）

> 遇到以下症状，按表内顺序处理。一线修复无效 → 走兜底，兜底无效 → 🔴 上报用户，禁止硬编。

| 触发条件（症状） | 一线修复（if） | 仍失败兜底（then） |
|---|---|---|
| 选族后 2 次都无新意 | 换「第二备选」主题重选 | 🔴 上报：向用户要更多 brief 信息（受众/预算/载体） |
| 组合后极端关不过 | 把「变」的力度 ×3（数值/尺度/反差加大） | 换强度卡（如 51 变态结果 / 67 变夸张） |
| 组合后故事关不过 | 给反差补一段因果链（谁→为何→结果） | 换叙事族（G）或加 32 变出理由 |
| 可行关不过（预算/技术超载） | 换低成本载体（装置→海报、视频→长图） | 切 B21 零预算 或缩小范围再质检 |
| 品牌一致关不过 | 换差异点（加 63 单一要素 或 60 文案主导） | 🔴 上报：向用户确认品牌核心差异资产 |
| 用户只说「给个 slogan/一句话」 | 先直接交付成品（1 句话），再附 1 行创意逻辑 | 若用户要长文案 → 移交 `master-copywriter` |
| 用户无 brief 只求灵感 | 随机抽 2–3 张卡洗牌启发 | 用「品类/场景选族表」兜底路由 |

## 四、组合拳模板（参考线索，禁止照抄）

> ⚠️ **这些组合是「验证过的起点」，不是「标准答案」。** 连续 2 个 brief 使用同一组合 = 路径依赖，强制换族。下方组合仅供启发，落地时须按主题 sub-skill 的卡表重新组合。

| 组合 | 用于 | 经典案例 | 勿照抄警示 |
|---|---|---|---|
| **A02 变大 + F17 游戏 + E36 同盟** | 想要 viral+口碑双爆 | 蜜雪冰城主题曲；可口可乐昵称瓶 | 案例里的「魔性神曲」只是载体之一，勿默认复制成歌 |

## 五、红线（绝对不做）

- ❌ **温和的变**：「logo 改小一点」「slogan 换个说法」——等于没变
- ❌ **先选载体再凑创意**：「我们做个 H5」开头——必败
- ❌ **极端但无故事逻辑**：反差大但读者记不住动机
- ❌ **明星当一切**：明星抢戏产品隐身
- ❌ **本地化当创意本身**：国际化卖点硬塞旗袍/京剧
- ❌ **公益 = 道德绑架**：把公益当遮羞布会反向 PR 灾难
- ❌ **执行 = 50 分**：idea 惊艳但执行拉胯，浪费 idea
- ❌ **年年变 logo**：品牌资产需要「不变」做锚点

## 六、输出格式

**默认交付 4 段**（按此顺序，缺段补齐）：

| 段 | 内容 | 约束 |
|---|---|---|
| 1. 【选族说明】 | 建议走哪个主题 | 一句话（≤30字） |
| 2. 【选卡说明】 | 挑了哪些卡、为什么是这几张 | 一句话（≤30字） |
| 3. 【执行思路】 | 按主题 sub-skill 工作流展开 | 3–5 条要点，含 1 个经典案例参照 |
| 4. 【质检】 | 四关打勾 | 每关 1 行「✓/✗ + 一句依据」 |

**输出裁剪规则（按请求判断，不默认问用户）**：
- 用户要「一句话/快想法」→ 只出第 1+2 段 + 第 3 段的一行浓缩，共 ≤80 字
- 用户要「完整方案」→ 4 段全出
- 用户只要文案 → 直接给成品（1 句 slogan / 1 段文案），再附第 2 段一行创意逻辑，不跑完整流程
