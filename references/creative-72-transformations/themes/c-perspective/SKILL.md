# 创意72变 · C · 视角重置

观众换 = 创意翻新。最便宜的戏剧工厂。

## 二、工作流（5 步）

1. **拿 brief** → 找出"信息交付的最核心场景"
2. **问"如果是 X 看，会怎样？"**
   - 观众第一人称 → 选 22 视角重置
   - 一镜到底 → 选 25 镜头在变
   - 拍看不见的 → 选 54 有形于无形
   - 拍内心戏 → 选 56 变在内心
   - 多视角并行 → 选 66 变分屏
3. **重写叙事逻辑**（用「3 问」模板，禁止只换场景不换故事）：
   - 问 1：新视角下，**谁**在看？（具体到身份/情绪/立场，如"刚失恋的快递员"）
   - 问 2：他/它看到了**什么别人看不到的**？（1 个信息增量，否则换视角无意义）
   - 问 3：看到后**发生什么**？（1 个因果事件，串联产品信息）
   → 3 问全答出才进入下一步；任何一问答不出 = 视角重置失败，回步骤 2 换卡。
4. **载体匹配** → 短视频 / Gopro / AR / 长图 / 互动
5. **沉浸感测试**（5 项量表，每项 0–2 分，≥7 分通过，否则回步骤 3）：
   - 视角切换后「我在这里」的代入感（0–2）
   - 画面是否只剩观众该看到的（无出戏信息，0–2）
   - 声音/镜头语言是否服务于该视角（0–2）
   - 信息增量是否在 10 秒内被感知（0–2）
   - 产品出现是否不破坏沉浸（0–2）

🔴 **CHECKPOINT**：沉浸感量表 <7 分 → 回到步骤 3 重写叙事，重试上限 2 次；仍不过 → 上报母索引换族。

## 三、组合拳

---

## 四、本主题红线

- ❌ **视角换了但故事没变**：换视角≠换内容，必须配套新叙事
- ❌ **一镜到底玩噱头**：为了长镜头而长镜头，没有节奏
- ❌ **内心戏=自言自语**：独白要让人认得出那是哪个"自己"
- ❌ **不可见=抽象**：抽象到不知所云=无效
- ❌ **分屏太散失去焦点**：分屏必须服务一个信息，不是炫技
