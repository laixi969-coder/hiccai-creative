# 创意生成五步流程

> 创意不是纯直觉，而是一系列**可以被描述、被教授、并不断重复的步骤**。
> 核心原则：**创意就是旧元素的新组合。**

本 skill 提供一个**可重复的创意生产技术**，用于把任何「现象/话题/产品/客户需求」转化为可落地的 Big Idea。

---

## 一、5 步流程（顺序关键，前一步未完成下一步无法进行）

| # | 步骤 | 核心动作 | 关键警示 |
|---|---|---|---|
| 1 | **吸收** | 让大脑尽量吸收原始素材（一般 + 特殊） | 此步骤最常被忽略；随身带笔记本记录客户/生活观察 |
| 2 | **咀嚼** | 把资料当成食物，用思维好好咀嚼 → **拆元素库**（见第四节组合机） | "完全发生在你的大脑思考中"，难描述 |
| 3 | **孵化** | 把问题交给潜意识（「drink problem」技巧） | 不期而至：剃须/沐浴/拂晓时浮出水面，不可强求 |
| 4 | **产出**（Eureka） | 创意自然浮出水面 → **用组合机焊接 + 3 问检验**（见第四节） | 必须先完成 1-3，否则产出只是噪音 |
| 5 | **检验**（黎明前的黑暗） | 把小创意放逐现实经受考验 + 修正 | 大多数创意需要耐心多次修正才有效 |

**核心信条**：「创意绝非偶然，而是一个循序渐进的过程。」

---

## 二、工作流（5 步操作版）

> 适用场景：拿到 brief / 现象 / 话题，准备出 Big Idea 时。

### 步骤 1：吸收原始素材
**操作清单**：
- **一般素材**：本品类历史经典案例、竞品广告史、行业教科书 / 顶级奖项（如 One Show）
- **特殊素材**：目标人群真实生活细节、街头观察、跨行业类比、客户的一手陈述
- **工具**：随身笔记本（随身带一本，记满客户观察）

**产出**：素材清单（不少于 30 条）

**检验**：素材够「杂」吗？至少跨 3 个不相关领域才算「宽」。

### 步骤 2：咀嚼素材
**操作清单**：
- 把素材做交叉对比：「这件事和那件事有什么共同点？」
- 找「遥远的类比」（distant analogy）—— 跨领域找相似结构
- **禁忌**：在咀嚼阶段就开始挑刺素材「这个不能用」—— 这是步骤 5 的工作

**产出**：5-10 条「跨素材的潜在关联」

**检验**：关联是否让你「惊讶」？平淡 = 咀嚼深度不够。

### 步骤 3：孵化（drink problem）
**操作技巧**：
- 把问题**明确化**：「我需要找到一个方法，让 X 人群产生 Y 行为」
- 把问题**抛给潜意识**：睡觉、散步、洗澡、剥须、驾车
- **「drink problem」**：白天喝咖啡时想问题/晚上酒精时想 → 白天又有新洞见
- **禁忌**：一直盯着问题不放 → 焦虑会扼杀孵化

**产出**：一个深夜 / 早晨的「灵光乍现」

**检验**：灵光是否有「啊哈！我找到了！」的突然感？

### 步骤 4：Eureka —— 创意浮出水面
**操作清单**：
- **立刻记下来**（笔记本 / 手机）—— 灵光消失极快
- 用 1 句话说清楚创意：「如果把 X 和 Y 这样结合，就是 Z 创意」
- 准备 3 个变体（同一个核心概念的不同表达）

**产出**：1 个核心创意 + 3 个变体

**检验**：创意是否「意外但合理」？

### 步骤 5：检验（黎明前的黑暗）
**操作清单**：
- 把创意**放回 brief**：是否解决了原问题？
- 找 3 个目标用户验证：他们的第一反应是什么？
- 检查品牌资产：创意是否损害品牌一致性？
- **修正直到有效**—— 大多数创意要修 3-5 次

**产出**：可落地执行的最终创意

**检验**：通过创意「冷板凳」（伯恩巴克标准）：是否**关联**+**戏剧性**？

## 三、两个普遍性原则（必读）

### 原则 1：创意完全发生在大脑内部
- 仅在「产出」之后才表现为外部行为
- 步骤 1-3 不能被任何外在工具替代

### 原则 2：语言是情绪体验的表征
- 改变一个词语可让广告反馈产生 **50% 差异**
- 写作时：与其「修饰」不如「替换」—— 寻找更精准的情绪对应词

## 四、组合机 —— 「旧元素的新组合」落地操作

> 「旧元素的新组合」不只是口号——它是一条可执行的操作路径。5 步流程负责「喂料和孵化」，**本模块负责「把两个旧元素焊成新创意」**。在步骤 2（咀嚼）与步骤 4（产出）之间执行。

### 4.1 元素库（先拆，再组）

把步骤 1 收集的素材拆成**原子元素**，每个元素必须是可独立识别的一块：

| 元素类型 | 例子 | 来源 |
|---|---|---|
| 场景 | 火锅店、地铁末班车、深夜便利店 | 特殊素材 |
| 情绪 | 焦虑、松弛、被需要、不服 | 人群观察 |
| 身份 | 打工人、宝妈、考研党、老广 | 目标人群 |
| 功能 | 解辣、降噪、即热、防水 | 产品卖点 |
| 媒介 | 电梯、外卖袋、发票背面、地铁把手 | 媒介洞察 |
| 文化梗 | 谐音、方言、表情包、网络热梗 | 一般素材 |

**拆解规则**：素材里每出现一个「可被替换的变量」就是一个元素。例：「蜜雪冰城= 奶茶店 + 神曲 + 雪王 IP + 低价」→ 至少拆出 4 个元素。

### 4.2 组合公式（旧+旧=新）

**核心动作**：取两个**不同领域**的元素，强制焊接，观察是否产生新意义。

```
新创意 = 元素 A（领域 X）× 元素 B（领域 Y）
         ↑ 要求 A 与 B 来自不相关领域
```

**执行步骤**：
1. 在元素库里随机挑 2 个**跨领域**元素（场景×情绪、功能×文化梗、身份×媒介……）
2. 强制问：「如果 A 用 B 的方式来表达，会发生什么？」
3. 记录所有「意外但可理解」的焊接结果（≥5 个，先不评判）
4. 用 72 变做强度放大（如 67 夸张 / 35 反转），再筛

**示例**（拿真实案例反推）：
- 蜜雪冰城 = 奶茶店（功能）× 洗脑神曲（文化梗）→ 「主题曲营销」
- 老乡鸡 = 快餐店（功能）× 养鸡场（场景）× 发布会（媒介）→ 「咯咯哒发布会」
- 蕉内 = 内衣（功能）× 「重新设计」（文化梗）→ 「重新设计基本款」

### 4.3 组合检验（3 问）

焊接出的候选创意，逐条过：

1. **意外吗？** 两个元素来自不同领域吗？同领域 = 平庸组合，重焊
2. **可理解吗？** 组合后的新意义 10 秒内能说清吗？说不清 = 太抽象，拆开换元素
3. **有立场吗？** 删掉品牌名，这句话还站得住吗？（伯恩巴克「关联+戏剧」标准）

3 问全 ✓ → 进入步骤 5 检验；任一 ✗ → 回 4.2 换元素重焊。

🔴 **CHECKPOINT · 组合上限**：同一轮最多焊接 3 次；3 次仍不过 → 回步骤 1 补素材（元素不够，组合就是无米之炊），禁止硬焊。

## 六、本 skill 红线

- ❌ **跳过步骤 1 直接产出**：素材不够 → 创意空泛 → 撞墙
- ❌ **步骤 2 开始挑刺**：过早评判会扼杀素材交叉
- ❌ **步骤 3 强求产出**：焦虑会破坏潜意识孵化
- ❌ **步骤 5 不修正**：90% 的初版创意都需要修
- ❌ **创意=文案写作**：创意是「关联」，文案只是载体之一
- ❌ **组合机=随机拼凑**：焊接前必须拆元素库；没有元素库就组合 = 空中楼阁
- ❌ **同领域焊接**：两元素来自同一领域 = 平庸组合，禁止

## 八、检验问题（自测清单）

完成 5 步流程后问自己：

1. 步骤 1：素材够「宽」吗？（≥30 条 / ≥3 跨领域）
2. 步骤 2：跨素材的关联让我「惊讶」吗？
3. 步骤 3：我给潜意识留足时间了吗？（是否经历了「drink problem」）
4. 步骤 4：创意「意外但合理」吗？
5. 步骤 5：通过「冷板凳」（关联 + 戏剧性）吗？

任一 ✗ → 回到对应步骤重来。
