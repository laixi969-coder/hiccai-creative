# 内容效果验证

仅在完整方案、增长计划、转化计划或用户要求复盘/测试时加载。交付简短、可执行的测量安排，不把自评当实测，不预设每项都要量。

## 按主目标选择指标

| 目标 | 主结果与口径 | 辅助诊断与边界 |
|---|---|---|
| 曝光 | 平台可提供的目标人群去重触达；不可得则说明观测局限 | 展示/播放是代理指标，不自动等于目标人群触达 |
| 心智 | 明确问卷对象和提问方式的品牌回忆、场景与品牌关联 | 品牌搜索/主页访问是辅助信号，不能单独证明心智建立；有条件比较曝光与未曝光群体 |
| 卖货 | 约定归因窗口内的支付订单、净成交收入或毛利贡献，按业务选一个 | 点击→支付转化率需分母为对应商品/页面点击；结合退款、获客成本与利润，GMV不能替代利润 |
| 线索 | 去重后的合格线索数；合格率=合格线索/去重有效线索 | 成本/合格线索、预约率、后续成交；说明资格规则，避免把垃圾咨询当增长 |
| 服务 | 有效预约或实际到场/履约，按业务主目标选定 | 预约→到场、到场→成交，不能用表单提交代替实际服务成交 |

同时注明数据来源、观察周期、分母、去重方法和归因口径。能用内容/活动标识、平台后台或CRM分组追踪时保持一致；用户未提供系统就提出记录方案，不假装已有追踪能力。不同平台的播放口径不直接混算。

## 最小实验

1. 先确认已有基线、流量和资源。无基线时先做小规模基线采集，预算/周期写建议值而非行业定律；不编点击率、转化率或必达销量。
2. 提一个可证伪假设，例如“场景型开头比抽象利益开头带来更多合格咨询”，生成对应 A/B 成品。
3. 每轮只改一个主要变量：人群角度、钩子、证据或 CTA 之一；比较时尽量保持受众、预算、渠道、时段和承接一致。有条件随机分流，无条件注明仅方向性对比。
4. 测试前确定主指标、业务最小有意义变化、可承受损耗和观察窗口。样本稀少、成交周期未结束时不仓促宣布赢家，也不凭几条评论断言显著。
5. 主指标改善才考虑扩大；流量涨但线索质量/退款/品牌关联恶化则先排查。记录原假设、版本差异、数据与下一步，避免每轮同时重写一切。

## 断点对应改动

- 触达低：先查受众与分发条件，不先把内容改成猎奇。
- 点击低：查封面、标题、需要是否明确；点击高但停留差，优先修承诺兑现。
- 看完但记不住品牌：加强品牌事实与关键情节/画面关联，保持资产重复。
- 看完不行动：查证据、选择阻力、offer与入口是否清楚。
- 咨询多但不合格：明确服务对象、适用门槛与广告承诺，不单纯加大投放。
- 合格线索多但成交少：查跟进、评估、报价、交付与销售周期；内容不能替代履约能力。
